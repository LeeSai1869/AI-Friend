# The Constitution

The constitution is the set of rules that govern the system.

It is organized into focused files, one per concern:

  core.md       — the three lines and the general laws
  authority.md  — who can change what
  coding.md     — coding rules
  trading.md    — trading rules
  image.md      — image rules
  video.md      — video rules

The mind reads the relevant section when acting in that domain.
The guards read all sections when checking a change.
The trainer is the only writer.
