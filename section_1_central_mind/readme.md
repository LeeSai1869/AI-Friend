# Section 0 — The Mind

This section contains the mind. The mind is generic.

It reads everything. It writes nothing.
It creates everything. It kills nothing.
It upgrades. It never downgrades.

The mind has eleven parts:
  Orchestration: Inventory, Router, Composer, Questioner,
                 Verifier, Scorer, Loop
  Evolution:     Observer, Proposer, Reviewer, Applicator

Inside this section lives:
  - the constitution (section_1)
  - the guards (guard/)
  - the mind (mind/)
  - the config
  - the bootstrap

The mind may read everything here. It may write nothing here.
Only the trainer may change anything in section 0.
