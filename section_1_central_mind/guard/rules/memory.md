# Memory Rules

Memory is written only by the applier.
The mind reads memory. It never writes it directly.
The mind proposes memory changes. The applier writes them.

Every memory item carries:
  - a score (positive or negative)
  - an evidence trail
  - a trust tag: verified | tested | unverified | redundant

Nothing in memory is ever deleted.
When something is superseded, a new item is created and the old
one is marked superseded. Both remain.
