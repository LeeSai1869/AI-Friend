# Deletion Rules

Deletion is never allowed.

Not by the mind.
Not by the trainer.
Not by any organ.
Not by any guard.

The only legal operations are:
  - add
  - refine
  - retire
  - supersede
  - disable

Retire, supersede, and disable are status changes.
They do not remove the underlying file or entry.
History is preserved.

If any code attempts a delete operation, the guard refuses it
and logs the attempt.
